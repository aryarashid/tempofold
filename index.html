    A plan with room to flex.

    Start with a synthetic example or a blank agenda. Give each block a duration, notes and a category. Protect blocks that must keep their time. Set minimums for everything that can flex.

    When the room runs late

    Open recovery, choose how many minutes to reclaim and review the proposed changes. Apply shortens only future flexible blocks, in agenda order. If there is not enough room, TempoFold shows the exact unresolved time. Undo is available until you advance to the next block or reset the timer.

    Timer behavior

    Start workshop sets a fixed finish target from the agenda’s total duration. The planning start time is for the run sheet only. The timer uses timestamps and continues across background tabs, device sleep and reload. It never moves to the next block by itself. Pausing stops the block timer without moving the finish target. Keep the device clock accurate.

    Your work stays here

    The current agenda and timer save in this browser’s local storage. Export JSON for a portable backup. Imports and example changes require confirmation before replacing your agenda. Export contains the agenda, not live timer history. Do not run this agenda in multiple tabs. Browser data can be cleared by your browser or device.

    Offline use is available after this app has cached its files. Check the status below the timer before disconnecting. A first visit needs a connection.

    Keyboard: Tab moves through controls, Enter activates buttons, and Escape closes dialogs. No global timer shortcuts interrupt typing. Screen readers can read the timer on demand; it does not announce every second.
